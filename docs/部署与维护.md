# 部署与维护

## 1. 环境

- Windows 10/11（其他系统可用，`启动.bat` 需自己调整）
- Python 3.12（项目在该版本下开发）
- Git（上传 GitHub 用）
- 可选：支持 Chat Completions 的 OpenAI 兼容模型服务

## 2. 安装

```powershell
cd D:\single_slit_tutor\single_slit_tutor
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

如果 PowerShell 阻止激活：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\.venv\Scripts\Activate.ps1
```

## 3. 配置 AI（可选）

不配置时，测量、数据记录、本地核对、图表仍可用；AI 解释、回答批改和报告草稿提示未配置。

推荐用环境变量：

```powershell
$env:TUTOR_MODEL = "deepseek-chat"
$env:OPENAI_API_KEY = "你的密钥"
$env:OPENAI_BASE_URL = "https://api.deepseek.com"
```

也可以创建 `填写密钥.txt`，每行 `KEY=VALUE`，程序启动时读取；终端已有同名变量时以终端为准：

```text
TUTOR_MODEL=deepseek-chat
OPENAI_API_KEY=你的密钥
OPENAI_BASE_URL=https://api.deepseek.com
```

`填写密钥.txt` 已在 `.gitignore` 中，**不要提交**。官方 DeepSeek 域名会关闭 thinking；模型需支持 Chat Completions。检查解释、回答批改、报告草稿不使用工具调用；旧版提问动作可能使用工具，最多 3 次。

## 4. 启动

```powershell
.\.venv\Scripts\python.exe app.py
```

打开 `http://127.0.0.1:7860`。Windows 也可双击 `启动.bat`。

程序是单用户内存会话：重启进程会清空当前学习会话；已保存 JSON 保留，但不能恢复界面。修改 `.py` 后必须重启。

## 5. 测试

```powershell
$env:PYTHONIOENCODING = "utf-8"
.\.venv\Scripts\python.exe tests\smoke_check.py
```

测试会启动一个临时 Gradio 服务（默认 7861）并关闭；如果 7861 被占用，先结束占用进程。

## 6. 数据与备份

- 会话文件：`records/<学号>/session_<日期>_<UUID>.json`
- 保存失败：页面会提示，点「重试保存记录」
- 备份：定期复制 `records/` 到项目外；不要提交到 Git
- 清空测试会话：结束会话或删除对应 `records/<学号>` 目录
- 恢复：JSON 不能恢复成界面；只用于审计/导出

`.gitignore` 已排除：


## 7. GitHub

### 首次上传

```powershell
cd D:\single_slit_tutor\single_slit_tutor
git init -b main
git add .
git status
git commit -m "Initial commit: torsion pendulum tutor"
git remote add origin https://github.com/你的用户名/仓库名.git
git push -u origin main
```

### 更新

```powershell
git status
git add .
git commit -m "说明这次改了什么"
git push
```

不要使用 `git add -f .`，否则可能把密钥、记录或备份强行加入。

### 认证

优先使用 Git Credential Manager 浏览器登录；或者生成 GitHub Personal Access Token（classic 的 `repo`，或 fine-grained 的 Contents 读写），在 Git 要求密码时粘贴 token。不要把 token 发给别人或写进代码。

### 检查

推送后确认仓库里没有：

- `填写密钥.txt`
- `records/`
- `.venv/`
- `backup_*/`
- 本地截图

如果密钥曾经被提交：立刻吊销/轮换；从 Git 移除并提交；如果已推送，使用 `git filter-repo` 或删除远程仓库重建。删除文件本身不足以消除历史泄露。

## 8. 常见故障

### `Invalid port: ':1]'` / Gradio 导入失败

`NO_PROXY` 里有 `[::1]`，httpx 0.28 解析失败。启动代码会尝试移除；如果仍失败，在终端检查：

```powershell
$env:NO_PROXY
```

移除 `[::1]` 后再启动。

### 7860 被占用

```powershell
Get-NetTCPConnection -LocalPort 7860 -State Listen
```

结束占用进程，或只保留一个 `app.py`。

### 页面能开但 AI 不回复

- 检查 `TUTOR_MODEL`、`OPENAI_API_KEY`、`OPENAI_BASE_URL`；
- 检查网络/代理；
- 检查模型是否支持 Chat Completions；
- 检查页面顶端错误提示和 `records/` 中的 `model_error` 事件；
- 模型超时为 20 秒，不自动重试。

### 图表中文/上下标异常

项目使用 Matplotlib mathtext 显示上下标；中文依赖系统字体（Microsoft YaHei/SimHei）。缺少字体时安装中文字体或修改 `charts.py` 的 `font.sans-serif`。

### 修改代码后页面没变

Gradio 进程不会热重载 Python。结束旧进程后重新启动：

```powershell
Get-CimInstance Win32_Process -Filter "Name='python.exe'" |
  Where-Object { $_.CommandLine -match 'app\.py' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
.\.venv\Scripts\python.exe app.py
```

### 记录太多

`records/` 是本地数据，可直接归档到项目外；不要删除正在使用的会话文件。
