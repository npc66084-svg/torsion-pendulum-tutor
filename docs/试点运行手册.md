# 试点运行手册

给在教室主机上开局域网试点的人。单机版仍然用原来的 `启动.bat`，不要改它。

试点代码在 `lan-pilot` 分支，目录是 `D:\扭摆测惯量\torsion-lan-pilot`。`main` 上的单机版不要拿来开课。

## 0. 组网

目标：让学生的设备能直接打开 `http://<主机IP>:7862/`。主机和学生在同一个局域网、能互相访问即可，不需要公网。

### 0.1 先判断教室网络能不能用

在主机上查 IP 和网络位置：

```powershell
Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -notlike "127.*" } |
    Format-Table IPAddress, InterfaceAlias, PrefixLength
Get-NetConnectionProfile
```

- 选**接教室网线或教室 Wi-Fi** 的那块网卡，不要选 VPN（如 Radmin VPN、Clash TUN）的地址。
- 记下 IP 和前缀长度。例如 `10.102.180.16/20`，同一网段大约是 `10.102.176.x`～`10.102.191.x`。
- 用另一台学生设备连同一个 Wi-Fi，看它拿到的 IP 是否在同一网段。

再测两台设备能不能互通：

```powershell
Test-NetConnection <主机IP> -Port 7862
```

如果学生设备能 ping 通/端口能连上，说明教室网络允许互访，走方案 B；否则走方案 A。

### 0.2 方案 A：自带路由器（推荐，最可控）

教室 Wi-Fi 常有客户端隔离或需要逐台认证，最稳的是自带一台普通无线路由器：

1. 路由器 WAN 口接教室网口（需要 AI 外网时），或先不接 WAN（只做局域网）。
2. 主机用网线接路由器的 LAN 口。
3. 学生在路由器 Wi-Fi 下连接。
4. 在路由器上给主机做 DHCP 保留（例如固定 `192.168.50.10`）。
5. 关闭路由器的「AP 隔离 / 客户端隔离」（家用路由默认关闭）。
6. 30 台设备建议 Wi-Fi 6、5 GHz、路由器放教室中间；人数多时加一个 AP。

这样学生访问 `http://192.168.50.10:7862/`，不受学校 Wi-Fi 隔离影响。需要 AI 时，路由器 WAN 必须能上网。

### 0.3 方案 B：直接用教室网络

确认同网段、能互访后：

1. 主机接网线或教室 Wi-Fi，固定 IP 或 DHCP 保留。
2. 按第 6 节加防火墙规则（注意网络位置可能是「公用」，规则要带 `remoteip=LocalSubnet`）。
3. 学生访问 `http://<主机IP>:7862/`。

### 0.4 方案 C：主机开热点（仅小班应急）

Windows「移动热点」带机量通常不到 10 台，30 人不要用，只适合临时演示。

### 0.5 容量与干扰

- 一个普通 AP 带 30 台笔记本会比较吃力；优先 5 GHz，必要时两个 AP。
- 主机用有线，不要用 Wi-Fi 当服务器。
- 学生不需要外网也能上课；只有主机需要访问模型 API。

## 1. 准备配置

1. 把 `试点配置.example.txt` 复制成 `试点配置.txt`。这个文件已被 git 忽略，不要提交。
2. 把 `COURSE_CODE` 改成课堂上口头发放的课程码。只用英文和数字。
3. 按 `docs/名单示例.csv` 做一份 `名单.csv`，放到项目目录。表头是 `student_id,name,pin`，中文表头 `学号,姓名,识别码` 也可以。保存为 UTF-8。
4. 同一学号只保留第一行。`pin` 留空表示这个学生不用填个人识别码；写了内容就必须填对。建议 4 位数字。
5. 要用「载入完整演示数据」，名单里必须有学号 `000000`。演示不会改成学生输入框里的学号。
6. API key 仍写在 `填写密钥.txt`，不要写进 `试点配置.txt`。

改完名单不用重启。学生下次点「开始学习」时会重新读文件。

`COURSE_CODE` 或 `ROSTER_FILE` 没填、文件不在，试点会拒绝所有人进入，不会变成不校验。

## 2. 启动

双击 `启动试点.bat`，或在项目目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\启动试点.ps1
```

脚本读取 `试点配置.txt`，不在窗口里打印课程码。本目录没有 `.venv` 时，会使用旁边单机目录里的 `.venv`。

默认监听 `0.0.0.0:7862`。学生浏览器打开 `http://<主机IP>:7862/`。

健康检查：

```powershell
python scripts\health_check.py http://127.0.0.1:7862/
```

打印「健康检查通过」才算页面能打开。

## 3. 学生怎么进

同一台电脑上的普通窗口、隐私窗口、另一个浏览器，才是三个学生。同一个浏览器的两个标签页共用一个登录，算同一个学生。

填学号、课程码。名单里这一行有识别码时再填识别码。课程码和识别码不会写入记录，也不会发给 AI。

错误课程码、不在名单、识别码不对，都不能开始。连续失败太多次后，要等 10 分钟。默认每个学号 8 次，全班合计 60 次，防止有人轮换学号试课程码。

同一个学号再次点「开始学习」会让旧窗口退出。这是 P1 已有的行为。

## 4. AI 限额

只在试点请求里生效。单机模式仍是原来的超时：多数 20 秒，提问 60 秒，不自动重试。

试点时：

- 模型请求放在最多 6 个线程里。界面先显示「处理中……」。
- 每个学生每分钟最多 6 次 AI 请求（`AI_RATE_LIMIT_PER_MIN`）。
- 实验报告草稿和总结草稿合在一起，每个学生每个自然日（北京时间）最多 3 次（`AI_DRAFT_LIMIT_PER_DAY`）。
- 单次 HTTP 超时 30 秒，客户端失败或超时会再试一次。
- 外层如果等得太久，只提示超时，不再开第二次，避免两个线程同时改同一份记录。
- 超限或失败时，本地核对和已填数据仍可使用。

## 5. 备份

每天课后可以执行：

```powershell
python scripts\backup_records.py --source records --dest D:\torsion-backup --keep-days 14
```

不写参数时，备份到项目下的 `备份\`。不要把备份目录放进 `records\`。超过 14 天的 `backup_日期` 目录会被删掉。

这个脚本不会自己登记到任务计划。要每天 23:00 自动跑，由教师在「任务计划程序」里新建任务，操作填上面的命令，起始于项目目录。本次没有在这台电脑上创建计划任务。

## 6. 防火墙、固定 IP、开机自启

这些要在教室那台主机上由管理员做。本次没有执行。

防火墙只放行 7862，并且限制在本地子网；不要做端口映射，不要放行「公用」的全部来源：

```powershell
New-NetFirewallRule -DisplayName "torsion-pilot-7862" -Direction Inbound `
    -Protocol TCP -LocalPort 7862 -Action Allow -Profile Any -RemoteAddress LocalSubnet
```

教室网卡常常被 Windows 识别成「公用」（`Get-NetConnectionProfile` 可看），所以不要只写 `profile=private`，否则规则不生效；用 `RemoteAddress LocalSubnet` 比直接开放公用网络安全。

固定 IP 或 DHCP 保留在路由器上设置。主机名可以用 `torsion-lab`。学生不要在校外访问。本期没有 HTTPS。

开机自启可以用任务计划：触发器选「启动时」，操作运行 `启动试点.bat`，并取消「只有在用户登录时才运行」以外，还要在电源选项里关闭睡眠。关闭 Windows 自动重启更新，或改到没有课的时间。

## 7. 出了问题

- 页面打不开：先在主机上跑健康检查。再看 `试点配置.txt` 里的端口，以及防火墙是不是放行了 7862、是不是只限本地子网。
- 学生设备能上网但打不开主机：多半是 Wi-Fi 开了客户端隔离，或不在同一网段；换方案 A 自带路由器。
- 所有人都进不去：多半是没配课程码或名单路径不对。
- 一个人进不去：对一下名单里的学号和识别码。刚改完文件可以直接再试。
- AI 没回复：本地核对仍然有效。看是不是超过每分钟 6 次，或当天草稿已经 3 次。
- 要回到单机版：关掉试点窗口，到 `torsion_pendulum_tutor` 用 `启动.bat`。不要合并 `lan-pilot`。
