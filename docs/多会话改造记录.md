# 多会话改造记录

试点分支 `lan-pilot` 的记录，含多会话、课程码和 AI 限流。过程见 [局域网开发记录.md](局域网开发记录.md)。操作步骤见 [试点运行手册.md](试点运行手册.md)。

## 改了哪些文件

| 文件 | 改动 |
|---|---|
| `app.py` | 单机全局槽保留。请求内通过 `_session()` / `_params()` / `_dock()` 读取当前学生。`PILOT_MODE=1` 且传入 `session_token` 时绑定 `UserContext`，并在开始前核对课程码。试点 AI 经 `_ai` 进入线程池。`launch()` 读取 `APP_HOST`、`APP_PORT`。每次 `next()` 单独 set/reset `ContextVar`；无参数版本时预览给出提示。 |
| `session_registry.py` | 新文件。签名 token、内存注册表、重复学号踢旧窗口、从 JSON 恢复；上下文锁改为普通 `Lock`，允许跨线程释放。 |
| `session_store.py` | 同一学号目录写入加锁；临时文件使用随机后缀；成功保存后写 `index.json`。会话 JSON 仍是 schema 1.2。 |
| `ui.py` | `build_ui(..., pilot=False)`。只有试点模式加入隐藏的 `BrowserState`、课程码、个人识别码、登录错误提示和隐藏的「恢复会话」按钮；取消 `single_user` 并发限制。页面加载后 1.4 秒自动点一次恢复按钮，避免 BrowserState 尚未从 localStorage 读出时覆盖旧 token。 |
| `pilot_auth.py` | 新文件。课程码、名单、可选识别码、登录失败限速。只在试点且带浏览器 token 时，于「开始学习」和「载入演示」前调用。 |
| `pilot_ai.py` | 新文件。试点 AI 线程池、每分钟次数、报告草稿每日上限、超时提示。 |
| `tutor.py` | 五个模型函数增加可选参数 `timeout`、`max_retries`。不传时仍是原来的 20 秒或提问 60 秒，且 `max_retries=0`。 |
| `tests/test_pilot_sessions.py` | 原有隔离测试改为带测试课程码和名单；增加拒绝、热更新、限速和 10/20/30 人并发；增加「有组但无参数版本不崩」回归。 |
| `tests/test_pilot_ai.py` | 线程池重叠、限流、失败重试、超时不再开第二次。 |
| `tests/test_pilot_ops.py` | 健康检查和备份脚本。 |
| `scripts/health_check.py` | 访问页面，打印通过或失败。 |
| `scripts/backup_records.py` | 复制 `records/`，删除超过保留天数的旧备份。 |
| `启动试点.bat`、`启动试点.ps1` | 读取 git 忽略的 `试点配置.txt` 后启动。`启动.bat` 未改。 |
| `docs/试点运行手册.md`、`docs/试点反馈表.md`、`docs/名单示例.csv` | 教师操作说明、课后记录表、假名单样例。 |
| `.github/workflows/ci.yml` | 试点冒烟也构建 `pilot=True` 界面，并带上课程码/名单；单机冒烟仍单独跑。 |
| `.gitignore` | 忽略 `.pilot/`、`试点配置.txt`、`名单.csv`、`备份/`。 |

未改：`tasks.py`、`stages.py`、`uncertainty.py`、`torsion.py`、`report_docx.py`、`charts.py`、`启动.bat`。

## 如何运行

单机，与基线相同：

```powershell
python app.py
```

试点：先复制 `试点配置.example.txt` 为 `试点配置.txt`，填好课程码和名单，再双击 `启动试点.bat`。手工启动时还要设置 `COURSE_CODE` 和 `ROSTER_FILE`，否则所有登录都会被拒绝。

```powershell
$env:PILOT_MODE="1"
$env:APP_HOST="0.0.0.0"
$env:APP_PORT="7862"
$env:COURSE_CODE="课堂上的课程码"
$env:ROSTER_FILE="名单.csv"
python app.py
```

工作目录是 `D:\扭摆测惯量\torsion-lan-pilot`。这个目录没有自己的 `.venv` 时，使用单机目录里已经装好的解释器。

## 已知限制

- 同一浏览器的多个标签页共享 token，算同一个学生。
- 同一学号在新窗口再次开始，会新建会话并让旧窗口退出，不会把旧文件里的进度搬到新窗口。
- 刷新恢复的是已经写入 JSON 的阶段、参数版本、测量组和结果。未点击保存的输入，以及图表「已生成」状态，不会恢复。
- 页面加载后约 1.4 秒才会自动恢复会话；如果浏览器极慢，可能先看到开始页再跳回工作台。
- 防火墙规则、固定 IP 和开机自启只写在 `docs/试点运行手册.md`，没有在这台电脑上执行。
- 已在 3 个无头 Edge 浏览器中验证登录、拒绝、隔离、刷新恢复和重复学号踢窗口；还没有在教室里用 30 台真实设备上过课。
- 外层 AI 等待超时后，原来的那次调用可能还在后台写完；正常的 HTTP 超时由客户端在 30 秒内重试一次，外层不再并行开第二次。

## 验收修复记录（2026-11-11）

P2 验收发现的问题与处理：

| 问题 | 处理 |
|---|---|
| 每个试点事件在 `finally` 里 `_ACTIVE.reset` 报 `was created in a different Context` | `handle` 改为每次 `next()` 前后单独 set/reset；`UserContext.lock` 改为普通 `Lock` |
| 登录失败只在日志里，页面无提示 | 新增 `#pilot-error` 错误区；认证失败、重复学号踢窗口、非法学号都会显示具体原因 |
| 「结束并新建会话」也会触发红色错误框 | 错误信息改用独立的 `pilot_error` 字段，不再复用状态文字 |
| 有标定组但没有参数版本时预览抛 `AttributeError` | `_stage_view` 检测 `params is None`，显示「先保存一个参数版本」；补回归测试 |
| 刷新后回到开始页，会话丢失 | 初始加载不再触碰 BrowserState；页面加载后 1.4 秒自动点隐藏的「恢复会话」按钮，读取已就绪的 token |
| CI 的 `PILOT_MODE=1` 冒烟没有构建试点界面 | 冒烟按 `pilot` 构建，并断言登录错误区可见；CI 试点步骤带课程码和名单 |

复验结果：39 个单元测试通过；单机/试点冒烟通过；3 个浏览器并发、刷新恢复、重复学号踢窗口、登录拒绝均通过；服务端日志无异常。
