# 多会话改造记录

试点分支 `lan-pilot` 的 P1 记录。过程见 [局域网开发记录.md](局域网开发记录.md)。

## 改了哪些文件

| 文件 | 改动 |
|---|---|
| `app.py` | 单机全局槽保留。请求内通过 `_session()` / `_params()` / `_dock()` 读取当前学生。`PILOT_MODE=1` 且传入 `session_token` 时绑定 `UserContext`。`launch()` 读取 `APP_HOST`、`APP_PORT`。 |
| `session_registry.py` | 新文件。签名 token、内存注册表、重复学号踢旧窗口、从 JSON 恢复。 |
| `session_store.py` | 同一学号目录写入加锁；临时文件使用随机后缀；成功保存后写 `index.json`。会话 JSON 仍是 schema 1.2。 |
| `ui.py` | `build_ui(..., pilot=False)`。只有试点模式加入隐藏的 `BrowserState`，并取消 `single_user` 并发限制。 |
| `tests/test_pilot_sessions.py` | 三学生隔离、并发、刷新恢复、踢旧窗口、伪造 token、启动参数。 |
| `.github/workflows/ci.yml` | 增加试点测试；冒烟测试分别在 `PILOT_MODE=0` 和 `PILOT_MODE=1` 下运行。 |
| `.gitignore` | 忽略 `.pilot/`（本机签名密钥）。 |

未改：`tasks.py`、`stages.py`、`uncertainty.py`、`torsion.py`、`report_docx.py`、`charts.py`、`启动.bat`。

## 如何运行

单机，与基线相同：

```powershell
python app.py
```

试点：

```powershell
$env:PILOT_MODE="1"
$env:APP_HOST="0.0.0.0"
$env:APP_PORT="7862"
python app.py
```

工作目录是 `D:\扭摆测惯量\torsion-lan-pilot`。这个目录没有自己的 `.venv` 时，使用单机目录里已经装好的解释器。

## 如何回滚

1. 单机目录停在 `main`。不合并 `lan-pilot`。
2. 标签 `v1.0-single` 指向 `55ecc91`，是加规划文档之前的单机代码。
3. 去掉 worktree：`git worktree remove ..\torsion-lan-pilot`。记录目录不要一起删。
4. 试点分支可以保留或以后删除。不要 `git push --force`。

`PILOT_MODE` 未设置时，试点分支上的程序也按单机会话启动。

## 已知限制

- 同一浏览器的多个标签页共享 token，算同一个学生。
- 同一学号在新窗口再次开始，会新建会话并让旧窗口退出，不会把旧文件里的进度搬到新窗口。
- 刷新恢复的是已经写入 JSON 的阶段、参数版本、测量组和结果。未点击保存的输入，以及图表「已生成」状态，不会恢复。
- 课程码、名单、AI 限流、防火墙和开机自启还没做。
- 没有在三个真实桌面浏览器里逐个点击；隔离和恢复由 `tests/test_pilot_sessions.py` 调用同一个 `handle` 入口验证。
