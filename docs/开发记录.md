## 2. 关键决策

- **学生只填最终结果**：\(I_1,K,I_0\)、\(I_{\text{实验}},I_{\text{几何}},E\)、\(I_{\text{总}}\)、斜率、截距；中间量和不确定度由本地引擎算。
- **本地核对与 AI 解释分离**：核对按钮不走网络，AI 只解释不一致；避免模型慢或失败时卡住检查按钮。
- **不给标准答案**：AI 检查、回答批改和报告都不返回隐藏真值或标准 K/I/斜率。
- **多组默认平均**：不限组数；要排除某组时用「作废」，旧记录保留，再追加更正组。
- **真实/虚拟隔离**：参数版本和阶段数据分命名空间，切换模式不混算。
- **阶段不硬锁**：学生可以随时切换阶段，未填项在预览/检查中提示。
- **记录追加式**：参数版本、组、检查、回答、报告都写 JSON；旧记录不硬删除。
- **演示数据**：开始页一键填好参数、周期、学生计算和回答，用于只验收按钮和图。
- **助教浮窗**：四边/四角可拖拽缩放；聊天消息独立气泡。

## 5. 已知限制

- **单用户**：一个进程只保留一个 `session`，不支持多人同时在线。
- **多组取平均**：没有“指定某一组作为采用值”的选择器；只能作废其他组。
- **没有导出按钮**：会话 JSON 自动保存，但暂未提供 CSV/JSON 下载。
- **真实模型需自行验收**：本地测试覆盖无模型/模拟调用；真实 DeepSeek 输出受模型和网络影响。
- **AI 报告是草稿**：结构、数据和结论都需要学生核对，不自动提交。
- **图表字体依赖系统**：缺少中文字体的机器可能出现中文标签异常。
- **旧版文档/代码**：`tasks.py`、`lab_records.py` 仍保留给旧动作和回归测试，但新阶段流程主要使用 `stages.py`。
