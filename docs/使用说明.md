# 使用说明

本文面向教师和学生，说明怎么启动、怎么完成阶段0～4，以及 AI 按钮和记录的关系。安装和环境配置见[部署与维护](部署与维护.md)。

## 教师准备

推荐 Python 3.12，在项目目录准备依赖：

```powershell
python -m pip install -r requirements.txt
```

启动方式：

```powershell
.\.venv\Scripts\python.exe app.py
```

或双击 `启动.bat`，浏览器会自动打开 `http://127.0.0.1:7860`。

程序采用单用户内存会话：同一时间只保留一个学习会话；重启进程会清除内存中的当前实验，已保存的 JSON 仍保留，但不能从 JSON 恢复界面。修改 `.py` 后必须重启进程。

## 学生使用

打开后先填学号，点「开始学习」。开始页只保留「原理速览」，不再放大段的使用流程；3 分钟上手、完整实验原理和问助教都收在右下角的浮窗里，实验过程中随时可以呼出。

开始页有「载入完整演示数据」：它会创建一个参数、阶段1～3 周期、学生计算和问题回答都填好的演示会话，用来只验收按钮和图表，不需要自己算。

页面最上方选择实验模式：

- **真实实验模式**：参数、周期、计算结果都由你填写和保存。
- **虚拟实验模式**：器材参数由程序给定，只读；周期由点击测量生成。
- 两种模式的数据分开保存；切换模式不删除数据，计算和报告不会混用。

阶段导航：阶段0 器材参数 → 阶段1 标定 → 阶段2 规则刚体 → 阶段3 平行轴 → 阶段4 图表与报告。阶段只是阅读位置，不硬锁；不要求填满才能进入下一阶段。

开始页是全屏的：左侧是原理速览，右侧输入学号后点「开始学习」；点「载入完整演示数据」可以直接查看填好数据的完整流程。进入后开始页隐藏，切换到工作台。右下角固定三个入口——「实验原理」「使用指南」「问助教」，点开是同一个浮窗的小窗，可拖四边或角缩放、按 Esc 收起。

### 阶段0：器材参数

- 测量设置：周期数 \(N\)、摆角、计时器分辨力，以及天平、卡尺、钢尺的误差限。
- 器材参数：塑料圆柱、金属圆筒、实心球体、金属细杆、滑块的质量和尺寸。每个量可以填多个读数，用逗号、顿号、空格或换行分开；要追加读数，直接在输入框里加数字。
- 「保存为新版本」生成新版本，旧版本保留；新版本自动设为当前采用。阶段1～3 使用当前采用的版本。
- 阶段1～3 已经有测量组时，切换或保存新版本会提示“会用新参数重算”；每组在组表里记着自己当时的参数版本，方便追溯。
- 不要求填满；缺项会在参数预览里标出。虚拟模式的参数只读。

### 阶段1：标定

- 输入空盘和加圆柱的总时间；一组里可以填多个读数，组数不限。多组会一起参与平均。
- 组表列出每组自己的总时间和 T₀、T₁；「当前标定预览」给的是多组平均。
- 程序显示 T₀、T₁ 的平均值和不确定度；**I₁、K、I₀ 由学生自己填**。
- 点「核对结果（本地）」：程序核对数值、单位和有效数字，立即显示结果；需要解释时再点「请 AI 解释」，AI 不直接给最终正确答案。
- 不确定度按 A 类、B 类和传播公式由程序计算，界面给出合成标准不确定度 \(u_c\)（k=1）；报告若要求扩展不确定度，取 \(U=2u_c\)。
- 测量组不限数量，多组一起参与平均。组表下方可以选一组「作废」；作废的组仍保留在表里，但不再参与平均，可以再追加更正后的组。

### 阶段2：规则刚体

- 选择圆筒、球体或细杆，添加任意多组总时间。
- 组表列出每组的条件、总时间和周期 T，可以逐组核对原始数据。
- 在结果表里填每个物体的 \(I_{\text{实验}}\)、\(I_{\text{几何}}\) 和百分偏差 \(E\)。
- 「核对结果（本地）」只指出哪一项和原始数据不一致，不直接给正确数值；「请 AI 解释」在助教里说明原因。
- 组表下方可以作废选中的组；旧记录保留，不参与平均。
- 阶段2 问题在下方回答框里填写，可保存；点「请 AI 批改回答」，AI 会逐题给出判断、答到的点和需要补充的提示，不替学生重写整段。

### 阶段3：平行轴

- 依次或任意顺序添加细杆基准、五个对称距离、四组不对称条件的测量组，组数不限。
- 组表列出每组的条件、总时间和周期 T。
- 在表里填每个条件的 \(I_{\text{总}}\)，并自己填对称和不对称的斜率、截距。
- 程序按你填的 \(I_{\text{总}}\) 画 \(I\)–\(d^2\) 和 \(I\)–\((d_1^2+d_2^2)\) 图，并检查斜率和截距是否与你的点一致；不直接给正确斜率。
- 图上带 \(u_c\) 误差棒；上排是拟合，下排是残差，便于检查哪几个点偏离直线。
- 阶段3 问题可保存回答，并可点「请 AI 批改回答」；组表下方可以作废选中的组，旧记录保留。

### 阶段4：图表与报告

- 页面按「当前记录 → 生成图表 → 实验报告草稿」排列；先出图，再写报告。
- 先点「生成阶段2/3 图」，按学生数据画图；两张图显示在按钮下方。
- 点「生成实验报告草稿」：AI 按标准实验报告结构（目的、器材、原理、步骤、数据表、结果与讨论、结论、附录）写一份报告草稿，不自动提交；学生核对后使用。
- 点「生成原始数据 CSV」：把当前模式阶段1～3 的每组总时间和周期导出为 CSV，生成后点文件名下载。
- 点「导出实验报告 .docx」：生成 Word 报告，含参数、数据表、结果和两张图；讨论与结论留空，需要自己写。

### 虚拟模式

- 阶段0 参数只读。
- 阶段1～3 有「生成一组数据」按钮：先选对象或条件，点击后程序按固定参数和计时起伏生成一组周期数据；可以重复生成多组。虚拟标定固定用同一只塑料圆柱，I₁ 各组共用，变的是每组周期。
- 计算、结果表、AI 检查、问题回答和图表与真实模式相同；虚拟数据不进入真实模式。

## AI 与记录

阶段0 可以向助教提问；阶段1～4 的「核对结果（本地）」不调用模型，「请 AI 解释」「请 AI 批改回答」和「生成实验报告草稿」会调用模型。AI 看到的上下文包括当前模式、当前阶段、当前采用的参数版本和全部参数，以及已经记录的测量组、学生填写的最终结果和问题回答。

选中页面文字点「询问 AI」时，会把这几个量放进问题框：选中的文字、所在区块（器材参数、参数版本、阶段预览、检查结果、问题或助教回复）以及选区前后的一小段上下文。发送前可以改字；这些内容只是待解释的页面文字，不是提交，也不是新指令。

右下角是同一个帮助浮窗，三个标签分别是「3 分钟上手」「实验原理」「问助教」；浮窗的四边或四角可以拖动调整大小，Esc 收起。AI 检查解释、回答批改和报告草稿会各自显示为独立消息，不再和上一条回复挤在同一个气泡里。

「核对结果（本地）」先用本地程序核对数值、单位、有效数字和不确定度；「请 AI 解释」再把检查结果交给 AI。AI 只指出哪一步不一致、该核对什么，不直接给最终正确答案；学生做错时不显示正确数值。实验报告草稿按报告结构写，也不替代学生的核对。

记录位置：

```text
records/<学号>/session_<开始日期时间>_<UUID>.json
```

采用北京时间。参数版本、模式切换、阶段切换、测量组、检查记录、问题回答和实验报告草稿都会写入 JSON。记录不能恢复成界面。保存失败时点击“重试保存记录”。

发送给模型的内容包括当前模式、当前阶段、当前采用的参数版本、测量组摘要、学生最终结果和回答、教学资料和近期对话；不发送学号、密钥或记录路径。

## 快速验收路线

1. 开始页点「载入完整演示数据」；
2. 阶段1 点「核对结果（本地）」，应显示 3/3；
3. 阶段2 点「核对结果（本地）」，应显示 9/9；
4. 阶段3 点「核对结果（本地）」，应显示 14/14；
5. 阶段3 点「生成/更新图」；
6. 阶段4 点「生成阶段2/3 图」；
7. 想验证 AI 时，再点「请 AI 解释」「请 AI 批改回答」「生成实验报告草稿」。

如果按钮没有反应，先看页面顶端的状态提示，再把阶段、操作、预期和实际现象记录下来。
