## 两类版本

- **单机版**：`main` 分支，每台电脑各跑一份，`启动.bat`，`127.0.0.1:7860`。
- **局域网试点**：`lan-pilot` 分支，一台主机，学生浏览器访问，`启动试点.bat`，`0.0.0.0:7862`。

单机版文档：使用说明、设计说明、开发记录、部署与维护。  
试点文档：试点规划、试点运行手册、局域网开发记录、多会话改造记录、试点反馈表。

## 维护约定

- 试点代码只在 `lan-pilot` 分支，`main` 保持单机版。
- `v1.0-single` 是单机版回滚点。
- 课程码、名单、API key、`records/` 不进仓库。
- 改完代码先跑 `tests/smoke_check.py`（单机和试点各一次）再提交。
